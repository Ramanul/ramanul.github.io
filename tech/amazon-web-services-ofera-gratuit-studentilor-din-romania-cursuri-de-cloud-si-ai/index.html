Amazon Web Services oferă gratuit studenților din România cursuri de cloud și AI

28 august 2026, 12:47 ~1 min citire Titlu sintetizat automat

Amazon Web Services a lansat programul Student Rewards pe platforma AWS Builder Center, oferind studenților din România acces gratuit timp de un an la peste 900 de cursuri online. Programul include materiale de pregătire pentru certificări, exerciții practice și resurse de învățare în domenii precum cloud computing și inteligență artificială. Pentru a beneficia de ofertă, studenții majori trebuie doar să își creeze un cont pe platformă.
