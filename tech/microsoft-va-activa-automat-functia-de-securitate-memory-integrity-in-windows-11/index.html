Microsoft va activa automat funcția de securitate Memory Integrity în Windows 11

2 septembrie 2026, 12:28 ~1 min citire Titlu sintetizat automat

Începând din octombrie 2026, Microsoft va activa automat funcția Memory Integrity pe dispozitivele Windows 11 eligibile pentru a proteja sistemul împotriva codului malițios. Deși sporește securitatea prin intermediul tehnologiei de virtualizare, activarea poate reduce performanța și numărul de cadre pe secundă în anumite jocuri video, în funcție de configurația hardware.
